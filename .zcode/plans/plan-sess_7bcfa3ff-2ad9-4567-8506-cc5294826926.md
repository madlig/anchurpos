# Rencana Rombak Total Halaman Manager/SFM

## Tujuan
Halaman manager/sfm yang menampilkan informasi produksi lengkap: tahap & durasi real-time tiap WO, defect/yield, panel detail WO, alert WO lambat, filter crew + sort. Card/tabel menampilkan info utama; klik WO → panel detail dengan info lengkap.

## Prinsip Desain (dari jawaban user)
- **Freezer BUKAN waiting step** — storage on-demand. TIDAK ADA alert freezer. Pre-pack on-demand sesuai pesanan/kebutuhan kosongkan freezer.
- **Alert produksi**: 1 adonan ~3 jam. Alert kalau WO in-progress di tahap produksi (DOUGH/MIXING/TRAY) dan >3.5 jam sejak `startedAt` belum masuk freezer.
- **Filter crew "keduanya"**: assign crew saat terbit WO (primary PIC) + filter juga bisa pakai crew dari log eksekusi.

## Perubahan File 3 (UTAMA): `app/manager/sfm/page.tsx` — rombak total

### A. State baru
- `employees` (crew list dari `/api/employees` filter role==="crew"), fetch di `loadAllData`.
- `selectedCrewFilter` ("all" | crewId), `sortBy` ("newest" | "progress" | "duration" | "yield").
- `detailWo` (WorkOrder | null) + `woLogs` (WorkOrderLog[]) + `loadingDetail` — untuk panel detail.
- `liveTick` (number) — state increment tiap 30 detik via interval, untuk re-render timer live.

### B. Live tick interval (BARU)
`useEffect` setInterval 30000ms → setLiveTick(t=>t+1). Untuk timer real-time di card/tabel/detail. Cleanup on unmount.

### C. Helper komputasi (useMemo / fungsi)
- `getStageInfo(wo)`: mapping `currentStage` → { label, color, isProducing, isFreezer, isDone }.
- `getActiveTimerMs(wo)`: step aktif → `now - currentStepStartedAt`; freezer → `now - freezerInAt`.
- `getTotalDurationMin(wo)`: jumlah semua `stepDurationsMinutes` values.
- `isStuck(wo)`: status IN_PROGRESS, currentStage di {DOUGH_COOKING,MIXING_EGG,TRAY_MOLDING}, dan `now - startedAt > 3.5 jam`. FREEZER/PRE_PACK TIDAK dianggap stuck.
- `getYield(wo)`: goodPcs / (goodPcs + defectPcs) * 100, atau goodPacks/(goodPacks+defectPacks).
- `getProgressPct(wo)`: per woType (PRODUKSI: trayPrinted/targetLoyang; PACKING: goodPacks/targetPacks).

### D. Metric cards rework (ganti 4 card generik)
4 card baru yang actionable:
1. **WO Aktif** (status !== COMPLETED/CANCELLED) — angka.
2. **Sedang Produksi Dapur** (currentStage di tahap produksi) — angka + subteks "X di Freezer".
3. **Rata-rata Yield** (% dari semua WO COMPLETED/IN_PROGRESS) — angka %, warna (hijau>90, kuning 80-90, merah<80).
4. **WO Perlu Perhatian** (stuck count) — angka + badge merah jika >0.

### E. Alert Banner (BARU)
Di atas tabel/card, jika `stuckWos.length > 0`: banner amber dengan list WO number + durasi + tombol "Lihat" → buka detail. Hanya muncul saat ada yang stuck.

- Dropdown **Urutkan**: Terbaru (default) | Paling Dekat Selesai | Durasi Terlama | Yield Terendah.
- `filteredWorkOrders` memo: apply variant + woType + crew filter, lalu sort.

### I. Panel Detail WO (BARU — side sheet)
Overlay custom (fixed inset-0, panel slide dari kanan width ~480px, overlay bg gelap) — konsisten dengan pola inline page ini, tidak install package baru. Trigger: klik row/card. Konten:

**Header:** woNumber, woType badge, status badge, tombol close (X).
**Section 1 — Ringkasan:**
- PIC crew, tanggal mulai, selesai, batchCode, expiredDate.

**Section 3 — Riwayat Aktivitas Crew:**
Fetch `GET /api/sfm/work-orders/[id]/log` saat buka detail. Timeline log (timestamp, crew, action: sub-batch/transisi/scrap, valueAdded, notes). Tampilkan sebagai feed chronologis (terbaru di atas). Loading skeleton via komponen `Skeleton` yang sudah ada.
