# Rencana Perbaikan Flow Crew SFM + Per-Step Time Tracking

## Tujuan
1. Memperbaiki flow crew PRODUKSI sesuai produksi nyata (bug MIXING_EGG kosong, TRAY_MOLDING nyangkut, jeda freezer).
2. Menambah **time tracking per-step** di mini dashboard: timer berjalan saat step dimulai, saat step berikutnya diklik → durasi step sebelumnya difinalisasi & step baru dimulai secara atomik di server.

## Data Model Baru (server-authoritative, tahan refresh)
Tipe `WorkOrder` sudah punya `stepDurationsMinutes?: Record<string, number>` dan `freezerInAt?`. Tambah **satu field baru**:
- `currentStepStartedAt?: Timestamp` — waktu server saat step saat ini dimulai.

(Tidak perlu ubah `types/index.ts` secara breaking — field opsional. Saya tetap akan tambahkan ke interface agar rapi.)

## Perubahan File 1: `app/api/sfm/work-orders/[id]/step/route.ts`

### A. Server-authoritative timing (ganti hitung client)
Baris 53–62 saat ini pakai `durationMinutes` dari client. Ubah:
- Baca `woData.currentStepStartedAt`.
- Jika ada: hitung `stepDurationMin = (now - currentStepStartedAt) / 60000`, tambahkan ke `stepDurationsMinutes[currentStep]`.
- Set `currentStepStartedAt = FieldValue.serverTimestamp()` (untuk step/sub-batch berikutnya).
- `durationMinutes` dari client tetap diterima sebagai **fallback** kalau `currentStepStartedAt` null (WO lama), tapi bukan sumber utama.

### B. Tracking `freezerInAt`
- Saat `targetStage === "FREEZER_CHECKPOINT"` dan `freezerInAt` belum ada → set `freezerInAt = FieldValue.serverTimestamp()`.
- Include `freezerInAt` & `currentStepStartedAt` di `batch.update(woRef, {...})`.

### C. Sub-batch (DOUGH_COOKING)
Setiap `SUB_BATCH` juga finalisasi durasi sub-batch sebelumnya via logika yang sama (di atas). Akumulasi tetap `+=` untuk `totalDoughBatchesDone`.

### D. Tidak diubah
- Overwrite loyang/pack (`=`) tetap, sesuai jawaban "input final sekali di akhir".
- Logic completion & inventory integration (productStocks increment, packaging deduction) tetap.

## Alur Verifikasi (Anda jalankan)
1. Buat WO PRODUKSI → crew buka → mini dashboard tampilkan "1. Masak Adonan ● (timer berjalan)".
2. Klik sub-batch 1.5 → step 1 durasi tercatat (mis. 8m), timer reset lanjut sub-batch berikutnya.
3. Lanjut → MIXING_EGG: drawer tampil info (tidak kosong). Mini dashboard: step 1 ✓ (durasi total), step 2 ● (timer).
4. Lanjut → TRAY_MOLDING: input loyang+pcs → "Masukkan ke Freezer". Stage maju ke FREEZER_CHECKPOINT (tidak nyangkut), `freezerInAt` tercatat.
5. Tutup/refresh app → buka lagi: WO masih ada, mini dashboard step 4 ● dengan timer "membeku" berjalan dari `freezerInAt` (tahan refresh karena server-side).
6. FREEZER_CHECKPOINT → "Sudah Beku" → PRE_PACK: input pack → closing → COMPLETED. Stok produk jadi bertambah.
